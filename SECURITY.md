# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **Cloud Drift Sentinel**, please report it privately:

1. **Do not create public GitHub issues for security reports.**
2. Email full vulnerability details to `adityasingh120444@gmail.com`.
3. Include reproduction steps, potential impact, and suggested mitigations.
